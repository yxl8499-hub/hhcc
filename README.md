# 再e亿下

面向大学生的校园减脂餐检索与饮食记录工具（Web MVP）。

## 运行

静态网页，无构建步骤，直接打开 `index.html` 即可使用。

## 功能

- 菜谱检索：关键词、来源、餐次、热量、预算、加餐场景筛选
- 菜谱详情：热量与营养、价格、位置、食材、做法、忌口提示
- 快速记录：菜谱一键记录、估算器自选组合、手动填写、拍照
- 今日看板：热量目标、剩余额度、三大营养素、随机推荐
- 记录与统计：按日记录、近 7 天趋势、营养构成、连续打卡
- 收藏与自定义：收藏菜谱、自定义加餐场景标签
- 数据管理：本地存储，支持 JSON 导出/导入

## 数据说明

- 菜谱为公开数据整理，热量、营养、价格均为估算值，仅供参考。
- 菜品图来自公开网络检索并本地缓存，正式发布前需确认版权与出处。
- 用户数据保存在本机，无需登录。
